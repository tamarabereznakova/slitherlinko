# GameStudio – Slitherlink

This project was created as part of my personal portfolio during my second year of studies at TUKE (Technical University of Košice).

Slitherlink is a fully interactive, multiplayer online web application game inspired by the classic Slitherlink logic puzzle.
The project was developed from scratch and includes the complete development process, from initial analysis and UML design to implementation and deployment.

NOTE: If the app is not active for some time, it falls automatically into "sleep". By loading it, you will be sending request to wake up and fully load.

# Features

- UML diagrams and project documentation
- Backend and frontend integration
- Puzzle generation and validation
- Full source code implementation
- User-friendly controls
- Responsive web interface
- Interactive Slitherlink gameplay

# Technologies Used

- Java
- Spring Boot + Maven
- HTML / CSS / JavaScript
- PostgreSQL
- Dockerfile + Git & GitHub to make it all run on Render.com

# Project Background

This project was developed as a university assignment and personal learning experience. The goal was to design, implement, and deploy a complete software solution while applying software engineering principles, object-oriented programming, database design, and web technologies.
Developing this project from concept to deployment significantly strengthened my confidence as a software developer. Working through the entire process independently—from design and architecture to implementation, testing, and deployment—showed me that I am capable of building complex projects on my own and solving challenging technical problems. The experience motivated me to continue creating software at a higher level and further develop my skills through future personal and professional projects.
